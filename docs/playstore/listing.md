## Full Description
Kaam connects you with verified home service workers in Kathmandu, Nepal.

Whether you need a house cleaner or a nanny, Kaam makes it easy to find trusted professionals who have been verified through document checks.

**For Customers:**
- Browse verified cleaners and nannies
- Book workers directly or post a job request
- Chat with workers before booking
- Pay directly via QR code or mobile transfer
- Rate and review after service

**For Workers:**
- Set up your profile and get verified
- Receive direct bookings from customers
- Browse and apply to open job requests
- Set your own hourly rate
- Build your reputation through reviews

**Features:**
- Phone OTP login — no password needed
- Verified worker badges for trust
- Real-time chat messaging
- Push notifications for bookings and messages
- Simple, clean interface

**Currently available in Kathmandu. More cities coming soon.**
